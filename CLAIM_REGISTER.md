# CLAIM_REGISTER.md

**Purpose:** The canonical register of every approved professional claim. This document separates *claims* from *evidence* — a standard practice in regulated documentation systems. The Evidence Traceability Matrix in `MASTER_BRAND_SPECIFICATION.md` is the authority on evidence levels; this register is the authority on canonical claim wording and where each claim is used.

**Relationship to other documents:**
```
Evidence (primary documents, employment letters, certificates)
  ↓
Evidence Register / Evidence Acquisition Plan  (evidence lifecycle)
  ↓
MASTER_BRAND_SPECIFICATION.md  (governance, evidence levels, traceability matrix)
  ↓
CLAIM_REGISTER.md  (canonical wording, public asset mapping)
  ↓
Public Assets  (CV, LinkedIn, Portfolio, Cover Letters, Interview Prep)
```

**How to use this register:**
- When drafting any public asset, reference Claim IDs rather than writing new wording.
- When a claim's evidence level changes, update the relevant row here and regenerate all listed public assets.
- When a new claim is approved, add a new row with the next sequential ID.
- Never add a claim to a public asset unless it has a row in this register with Status: **Approved**.

## Claim Status Definitions

| Status | Meaning |
|--------|---------|
| **Draft** | Idea or unverified claim; must not be published |
| **Pending** | Awaiting owner decision or evidence; must not be published |
| **Approved** | Cleared for use in Public Assets |
| **Restricted** | Supported by C/Low evidence; internal only |
| **Retired** | Claim no longer used or relevant |
| **Superseded**| Replaced by a newer version/wording |

## How to Extend This Register

1. **New claim approved** → Add next sequential ID (C-025, C-026…). Set Status based on Evidence Quality.
2. **Evidence received** → Update Evidence Quality, Public Confidence, and Status. Update "Used In" if status changes to Approved. Record in Change Log.
3. **Claim retired** → Set Status to Retired. Add date and reason to Notes. Remove from all Public Asset Claim Maps. Do not delete the row — maintain the ID for audit trail purposes.
4. **Wording changed** → Update Canonical Wording. Record old wording in Notes with the date it changed. Regenerate all listed public assets.
