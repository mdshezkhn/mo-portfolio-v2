**Status:** Planning complete. Sprint 0 (content extraction) in progress. No implementation until Sprint 0 exit criteria are met.

## Core principles
1. Evidence over claims – every statement traceable to a source
2. Nothing AI-invented – no fabricated achievements, dates, statistics, or testimonials
3. Safeguarding first – no identifiable students without documented consent
4. Design for longevity – timeless over trendy
5. Accessibility (WCAG 2.1 AA) in every sprint, not at the end

## Stack
GitLab Pages · HTML5 · CSS3 · Vanilla JS · Fraunces + Manrope · No frameworks, no build tools
