# Career OS

> **Every month, leave the repository with more evidence than you found it.**

> **The repository is not the product. The educator is the product.**

Career OS is not a résumé generator.
It is not a portfolio builder.
It is not a branding framework.

Career OS exists to ensure that professional claims remain traceable to authentic evidence, consistently represented across every recruiter-facing artifact, and reproducible over time.

The system assumes that no amount of persuasive writing can substitute for genuine professional practice.

---

## The Philosophy

**Professional credibility emerges from authentic practice; preserved evidence merely allows others to verify it.**

**Professional credibility emerges from verified evidence accumulated over time. Recruiter-facing artifacts are publications of that evidence, not independent sources of truth.**

The causal chain starts in the classroom, not in the repository. Evidence doesn't create credibility. Good teaching creates credibility. Evidence preserves it. The compiler communicates it. The recruiter evaluates it. The job offer recognizes it.

Everything in Career OS exists to make the educator easier to understand, never to make them appear to be something they are not.

---

## The Architecture

Every durable system eventually converges on the same architecture:

1. **Capture reality:** Gather undeniable evidence of professional practice.
2. **Establish a single source of truth:** The canonical data repository (`career-data/facts/`).
3. **Define governance:** The rules that dictate what constitutes a valid claim (`governance/`).
4. **Automate transformations:** The compiler engine (`career build`).
5. **Verify outputs:** Modular certification of compiled assets (`career certify`).
6. **Measure outcomes:** Track recruiter response, interviews, and offers over time (`DASHBOARD.md`).
7. **Resist unnecessary complexity:** No new infrastructure unless it demonstrably improves recruiter outcomes.
