# private/

**This folder is OUTSIDE the Git repository and will NEVER be deployed.**

Store sensitive personal documents here. Nothing in this folder should be uploaded to GitHub, GitLab, or Gitee.

## Contents

| Folder | Store Here |
|---|---|
| `Passport/` | Passport scans |
| `Visa/` | Visa documents and work permits |
| `PCC/` | Police Clearance Certificates |
| `Contracts/` | Employment contracts |
| `Original Certificates/` | High-resolution original certificate scans |
| `Medical/` | Medical certificates and check-ups |
| `Personal Notes/` | Personal notes, reflections, journals |

## Why these are private

These documents may contain:
- Government-issued ID numbers
- Personal identification data
- Third-party employer information
- Student-related data protected by GDPR/local data laws

## For the portfolio

If you need to show certificates publicly, create a compressed, watermarked **preview thumbnail** and store that in `mo-portfolio/assets/images/certificates/`. Link to the recruiter-downloadable PDF in `mo-portfolio/assets/downloads/`.

Original, unredacted scans stay here — never inside the website folder.
