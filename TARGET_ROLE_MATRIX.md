## How to Use This Matrix
1. When applying for a role, identify the closest match from the **Target Role** column.
2. Use the corresponding **Generated Output File** (e.g., `CV_EAL.pdf`).
3. If regenerating an asset, ensure the template specifically highlights the **Required Claims**.
4. The Master CV should rarely be used for direct applications; it serves as the complete record from which variants are derived.
