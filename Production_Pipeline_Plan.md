# Production Pipeline: Evidence Acquisition & Portfolio Implementation

## Project Definition
**Success criterion:** Every significant claim on the portfolio is supported by authentic evidence, and the finished portfolio increases recruiter confidence.

## Achievement Library (generates all downstream copy)
Achievements live once as *canonical data* in `Achievement_Library.md` (core fact, context, impact, evidence, hiring value); channel views (CV bullet, LinkedIn line, interview answer, portfolio paragraph) are generated on demand, not stored as parallel copies. Pipeline: `Evidence Source → Evidence Register → Achievement Library → Career Timeline → Portfolio / CV / LinkedIn / Interview Prep / Cover Letters`. Presentation-only changes (wording, order, layout) do not require a library entry.

## Phase 1: Evidence Acquisition (Tier 1 Priority)
1. **Teaching Demonstration Video**
   - Record 5-7 minute classroom-style demonstration
   - Focus on one complete lesson segment
   - Include student interaction and feedback loop

2. **Anonymized Student Work**
   - Select 3-4 examples showing progression
   - Remove all identifying information
   - Include brief context notes

3. **Research Brief**
   - One-page summary of PGCE action research
   - Key findings with simple chart/graph
   - Link to full paper in portfolio

4. **Classroom Photos**
   - 2-3 high-quality images
   - Obtain proper consent for use
   - Focus on engagement moments

## Phase 2: Portfolio Implementation
- Map each evidence item to specific portfolio claims
- Remove placeholder text
- Ensure no unsupported claims remain
- Add concise captions linking to evidence

## Phase 3: Validation
- Recruit 3 independent reviewers (non-academic)
- Time: 30-second initial scan
- Collect feedback categorized by:
  - Clarity of claims
  - Strength of evidence
  - Recruiter confidence impact

## Phase 4: Iteration
- Changes only if testing reveals gaps
- Document rationale for each change
- Version 1.1 only if justified by evidence

## Application Package Consistency Audit
**Elements to align:**
- Professional headline (CV, LinkedIn, Portfolio)
- Career chronology (dates, roles, progression)
- Core strengths (3-4 key points, consistent)
- Measurable achievements (quantify where possible)
- Contact information (format, availability)
