# Evidence Index

This document tracks all verified documentary evidence supporting the claims and employment records in the portfolio, processed in order of recruiter value.

## Verification Philosophy
Evidence is verified against **claims**, not just documents. A single document can verify multiple claims simultaneously (e.g. employment dates, official title, work location).

## 5-Step Processing Workflow
1. **Ingest Document:** Receive and store document securely in `/private/`.
2. **Create Record:** Log the document in this index using the standard schema.
3. **Map Claims:** Identify all claims the document supports.
4. **Consistency Review:** Compare against existing records to ensure no contradictions.
5. **Update Canonical Profile:** Only after the above steps are complete, update `CANONICAL_PROFILE.md` and regenerate downstream assets.
